# Аудит Ирландии (IRE) и план переработки

Дата: 17 ноября 2026 года. Целевая версия Hearts of Iron IV: **1.19.4.1**.
Исследованный commit: `f483f3682e0387aac542528b9d95a2464808a7ce`.
Ветка аудита: `docs/ire-audit`.

## 1. Вывод и границы достоверности

В репозитории нет законченного игрового модуля Ирландии. Есть четыре пары
локализаций национальных духов, пустой файл решений и списки названий войск.
Определения этих четырёх духов, их выдача, собственное дерево IRE, персонажи,
события и военно-промышленные организации (ВПО/MIO) не найдены.

Это **статический аудит**, а не подтверждение работоспособности мода.
Исполняемый файл HOI4 и каталог игры в доступных проверенных местах не обнаружены.
Базовые файлы игры и DLC версии 1.19.4.1 не предоставлены. Поэтому нельзя установить
фактический стартовый состав IRE, выбранное движком дерево, корректность загрузки
всех скриптов или совместимость с конкретным набором DLC.

Отсутствие файла в моде не означает отсутствие объекта в игре: Kachanlot является
слоем поверх базовой игры. Его зависимости от vanilla нужно сверить с установленной
1.19.4.1. Ниже «нет» означает «нет в исследованном checkout», если не указано иначе.
Требование качества уровня официального DLC здесь превращено в проверяемые этапы;
это не утверждение об эквивалентности будущего результата продукту Paradox.

В рамках аудита добавлен только этот документ. Игровые файлы не изменялись.

### 2.2. Глобальные точки взаимодействия

- `common/ideas/_economic.txt` и `_manpower.txt` меняют общие законы. Баланс IRE
  нужно измерять в Kachanlot, а не переносить числа из vanilla.
- `common/on_actions/kalchanlot_on_action.txt:3–20` вызывает `update_oil_factories`
  на старте для стран и в `on_monthly`. Комментарий про неделю не соответствует
  имени месячного хука; это замечание документации, не доказательство сбоя движка.
  Сам эффект определён в `common/scripted_effects/hosttool_scripted_effects.txt:1`.
- `common/on_actions/horsttool_on_actions.txt`, `common/scripted_guis/`,
  `interface/horsttool.gui`, `common/dynamic_modifiers/Horst_tool_modifiers.txt`
  образуют отдельную систему host tool. Её переменные не переиспользовать для IRE.
- `common/on_actions/00_on_actions.txt` — большой общий файл, в том числе несколько
  блоков `on_startup`. Не заменять его ради одной страны и не полагаться на
  непроверенный порядок выполнения разных файлов.
- `events/BMCR_events.txt:10` вызывает `BMCR_se_update_all`; определения в локальном
  `common/` не найдено. Нужно выяснить его происхождение по vanilla/логам/зависимостям.
  Это отдельный риск интеграции, а не доказанная причина отсутствия духов IRE.

## 4. Как устроены основные системы

### 4.1. Национальные фокусы

`common/national_focus/mexico.txt:14–58` показывает `focus_tree`, уникальный `id`,
вес выбора `country`, ограничение по DLC, `default = no`, расположение непрерывных
фокусов. Узел содержит ID, иконку, координаты, стоимость, AI и `completion_reward`.
Далее используются `prerequisite`, `mutually_exclusive`, `relative_position_id`,
`available`, `bypass` и `cancel_if_invalid`.

Для IRE недостаточно положить файл в каталог: дерево должно выиграть выбор для
нужного тега и набора DLC. Нужны уникальный `IRE_focus_tree`, IRE-префиксы узлов,
проверки достижимости, симметричные взаимоисключения, отсутствие циклов и
понятные условия bypass при исчезновении партнёра. `ai_will_do` узлов не заменяет
план стратегического пути AI. Синтаксис и численные стоимости сверять с 1.19.4.1.

### 4.2. Идеи и назначение странам

Цепочка работы: **определение ID → эффект в country scope → подходящие условия
сохранения → отображение и действующие модификаторы**.

- `common/idea_tags/00_idea.txt:8–24`: `hidden_ideas` скрыты,
  `country` имеет `type = national_spirit`. Для видимых духов нужен соответствующий
  раздел `ideas = { country = { ... } }`, а не hidden или слот экономического закона.
- Определение задаёт `picture`, `modifier`, ограничения, стоимость удаления,
  при необходимости `on_add` / `on_remove`. Само наличие определения не выдаёт дух.
- History страны выполняет стартовые эффекты. Пример: `history/countries/ROM - Romania.txt`
  выдаёт `neutrality_idea`, а другие идеи — внутри проверки DLC.
  Датированные блоки имеют значение: `history/countries/FRA - France.txt:229–251`
  содержит выдачу идей в `1939.1.1`; нельзя ожидать их на старте 1936 года.
- Фокус/решение выдаёт идею через `completion_reward` / `complete_effect`.
  Событие — через `immediate` либо выбранный `option`.
  On-action может вызвать централизованный scripted effect в scope IRE.
- `common/scripted_effects/GER_scripted_effects.txt:1–48` показывает переходы
  `swap_ideas = { remove_idea = ... add_idea = ... }` с проверкой `has_idea`.
  Удаление через `remove_ideas` нужно отличать от ключа `remove_idea` внутри swap.
- `allowed` и `available` — ограничения, не команда выдачи. В существующих
  scripted-only идеях встречается `allowed = { always = no }`; нельзя объявлять
  этот шаблон автоматически сломанным. Конкретное поведение назначения и
  `cancel`, `cancel_if_invalid`, `allowed_civil_war` проверять по версии и логам.
- Персонаж с `advisor` и `idea_token` — отдельный механизм от country spirit.
  Определение, `recruit_character` и фактический найм советника — разные стадии.
  Не назначать всех советников активными национальными духами.

### 4.3. Решения, события, персонажи

- `common/decisions/FRA.txt:1–75`: категория содержит решения/миссии, `allowed`,
  условия, таймаут и `timeout_effect`. `common/decisions/ENG.txt` показывает
  стоимость, видимость, `fire_only_once`, `complete_effect` и AI. Новой категории
  потребуется собственное определение в `common/decisions/categories/`;
  отсутствие этого каталога у мода не мешает ему использовать категории vanilla.
- `events/BMCR_events.txt:1–13`: `add_namespace`, `country_event`, ID, hidden,
  `is_triggered_only`, `immediate`. В `events/kachanlont_events.txt` есть
  события с самостоятельным `trigger`, а также событие с вариантами ответа.
  Для IRE предпочтительны адресные вызовы и ограниченные пульсы вместо частого
  глобального опроса. Нужны однократность сюжетных событий, корректные ROOT/FROM,
  AI-ответы и обработка отказа/исчезновения участников.
- `common/characters/ROM.txt:1–100`: `characters`, портреты, `country_leader`,
  ideology subtype, `advisor`, `slot`, `idea_token`, `traits`, ограничения тега.
  `history/countries/ROM - Romania.txt:47–75` рекрутирует персонажей.
  Типы идеологий сверять с `common/ideologies/00_ideologies.txt`; не путать
  группу `democratic` с подтипом `conservatism` и партийной принадлежностью.

### 4.4. ВПО и уникальные механики

`common/military_industrial_organization/organizations/ENG_organization.txt:9–110`
показывает наследование `include`, `allowed`, `visible`, `available`,
`initial_trait`, добавление traits и модификаторы организации/техники.
`00_generic_organization.txt` содержит общие шаблоны с исключениями стран по DLC;
IRE не исключена из начального generic tank allowed-блока. Это не доказательство
доступности всех generic ВПО и не подтверждение их фактического появления.
В контексте ВПО встречается `FROM` для страны; нельзя механически переносить
country-scope проверки из идей. Нужен тест назначения ВПО на исследования и линии.

Для экономики/общественных кризисов доступны dynamic modifiers, переменные,
решения и события. `common/bop/` уже используется другими странами, но вводить BoP
для IRE стоит только при ясном игровом конфликте и установленной DLC-политике.
Сначала достаточно собственных переменных и решений; GUI — после работоспособной
модели, а не вместо неё.

## 5. Почему духи могут не появляться или работать неправильно

| Приоритет / статус | Причина | Проверка и будущая мера |
| --- | --- | --- |
| P0, подтверждено в checkout | Есть текст, но нет определения четырёх ID | Создать `common/ideas/IRE.txt`; искать точные ID, а не только название страны |
| P0, подтверждено в checkout | Нет пути назначения этих ID | Выбрать один стартовый источник; проверить history и вызов init в scope IRE |
| P1, риск | Новый history заменяет одноимённый vanilla-файл | Перед добавлением извлечь полный оригинал 1.19.4.1; сохранить капитал, технологии, OOB, партии, рекрутирование, даты и DLC-варианты |
| P1, риск | Эффект попал в scope региона, ENG или FROM вместо IRE | Проверить цепочку scope и результат `has_idea` именно у IRE; не рассчитывать на глобальный ROOT |
| P1, риск | Идея выдаётся только в 1939, по другому DLC или после невызванного события | Проверить дату, DLC, trigger, namespace, on-action и все условия вызова |
| P1, риск | Удаление через cancel/другой фокус или повторную инициализацию | Найти все add/swap/remove; запускать миграции и init с явной защитой от повторов |
| P1, риск | Неверная категория/конфликт ID | Проверить `country` против `hidden_ideas`/законов, регистр ID, дубль в базовой игре и других модах |
| P1, риск | Скрипт не разобран движком, мод не активирован или загружен другой файл | Проверить активный playset, пути, регистр Linux, error.log и весь блок со скобками; наличие BOM в локализации уже подтверждено |
| P2, риск | Дух есть, но модификатор неизвестен версии/даёт другой знак | Проверить actual modifier definitions и эффекты на показателях, а не только значок |
| P2, риск | Пропал только текст/значок | Сверить `_desc`, язык, `GFX_idea_*`, `texturefile`; графическая проблема не доказывает отсутствие эффекта |
| P2, риск | Старый save не получает новый history; релиз/гражданская война дублирует бонусы | Тестировать новую игру отдельно от загрузки; определить политику миграции, original_tag и наследования |

Рекомендуемый будущий контракт: один `IRE_initialize_country` для собственных
переменных и духов, защищённый `IRE_initialized`; стартовый history вызывает его
один раз. Нельзя применять init при каждой загрузке и тем самым возвращать снятые
дебаффы. Флаги последующих реформ и условия исчезновения страны должны быть
описаны отдельно. On-action нужен только там, где history недостаточно, например
для явно поддержанного освобождения страны. Этот контракт пока не реализован.

## 6. Историческая постановка 1936 года

Это исходные требования к дизайну, **не извлечённые параметры стартовой IRE**.
Числа населения, фабрик, войск, партийной популярности и ресурсов требуют источников.

- На 1 января 1936 года — Ирландское Свободное государство; Éamon de Valera
  возглавляет Executive Council, Fianna Fáil у власти. Не называть его Taoiseach
  до конституционных изменений 1937 года. Конституционное положение в Содружестве
  не приравнивать автоматически к игровой марионетке ENG или членству в Союзниках.
- Торговая война с Британией (1932–1938) продолжается. Долги, тарифы и зависимость
  аграрного экспорта должны создавать выбор с ценой, а не бессрочный плоский штраф.
- Северная Ирландия под британским управлением. Соглашения 1938 года и Treaty
  Ports не дают автоматического воссоединения острова. Результат переговоров
  должен зависеть от ответа ENG и международной обстановки.
- Конституция 1937 года, соглашения 1938 года и Emergency 1939 года — отдельные
  стадии исторического пути; не выдавать их результаты сразу в 1936 году.
- Католическая церковь влиятельна, но не является отдельной тоталитарной партией.
  Наследие гражданской войны, IRA, конституционные республиканцы и Blueshirts
  должны быть разными силами. Запрет IRA в 1936 году — событие, не стартовая данность.
- Малая индустрия, эмиграция, ограниченные ресурсы и оборонные возможности —
  основа экономического/военного баланса. Не дублировать один штраф одновременно
  в населении, законе, духе и dynamic modifier без расчёта итогового эффекта.

Перед реализацией завести таблицу «факт — дата — источник — игровое отображение».
Источники для последующей проверки: Irish Statute Book (конституционные акты,
Emergency Powers Act), Documents on Irish Foreign Policy / Royal Irish Academy
(переговоры и внешняя политика), Oireachtas debates, National Archives of Ireland,
CSO (перепись 1936), Military Archives Ireland (Defence Forces), документы ESB и
истории предприятий. Эти материалы в данном аудите не открывались; количественные
значения и биографии не объявляются подтверждёнными исследованиями.

## 7. Предлагаемая архитектура переработки

### 7.1. Ветки и игровые циклы

| Ветка | Содержание | Ограничения и последствия |
| --- | --- | --- |
| Историческая Fianna Fáil | Конституционная самостоятельность → 1937 → урегулирование 1938 → Emergency | Баланс нейтралитета, снабжения и британского давления; без гарантированного воссоединения |
| Парламентская альтернатива Fine Gael | Выборы, институциональные реформы, торговый компромисс | Сохранить политический процесс; сотрудничество с ENG не равно немедленному вступлению в войну |
| Лейбористская/социалистическая | Социальная коалиция, профсоюзы, затем опциональная радикализация | Демократический Labour и коммунистический переворот — разные развилки с разными последствиями |
| Радикально-республиканская | Конфликт вокруг IRA, легализация/подавление, риск раскола и войны | IRA не равна фашизму; объединение через давление требует цены, кризиса и реакции ENG/NIR |
| Авторитарная правая, альтернативная история | Маргинальные правые, мобилизация сторонников, захват институтов | Не выдавать правление O'Duffy за историческую норму; исторический AI не выбирает её |
| Общая экономика | Аграрный экспорт, энергетика, инфраструктура, индустриальная диверсификация | Выбор между экспортом, самодостаточностью и импортом; не производить бесконечные фабрики решениями |
| Общая оборона | Defence Forces, резерв, береговая оборона, авиация и снабжение | Небольшая качественная армия; закупки и обслуживание вместо бесплатного большого флота |

Уникальные циклы: (1) торговая зависимость/переговоры с ENG; (2) внутреннее
республиканское давление и легитимность государства; (3) нейтралитет в мировой
войне, безопасность портов и дефициты. Раздел острова — отдельная дипломатическая
цепочка поверх этих циклов. Каждая переменная должна иметь диапазон, источники
изменения, пороги, UI-подсказку, восстановление после кризиса и предел бонусов.
Не добавлять сразу несколько конкурирующих шкал для одного и того же давления.

Предлагаемые цепочки событий: начало конституционной реформы; выборы/конституция
1937; переговоры 1938 с принятием/отказом ENG; реакция на европейскую войну;
Emergency и парламентский контроль; IRA и внутренние кризисы; британское
предложение об участии в войне; раздел/воссоединение и переходная интеграция.
Учитывать существующий `wtt_britain.24`, а не писать параллельный дубликат.

### 7.2. Персонажи, советники, ВПО

Кандидаты для исторической проверки ролей и дат: Éamon de Valera, W. T. Cosgrave,
William Norton, Seán Lemass (промышленность), Seán MacEntee (финансы), Frank Aiken
(оборона), Joseph Walshe (дипломатия), Michael Brennan (военное руководство).
Eoin O'Duffy и Peadar O'Donnell — кандидаты альтернативных направлений с отдельной
проверкой организаций, дат и политической эволюции. Не назначать всех доступными
в 1936 или объединять разные политические движения ради четырёх идеологических кнопок.
Для каждого: источник, доступность, роль, стоимость, черты, портрет, конфликт ролей,
условия увольнения/смерти и переворота. Переиспользовать существующие vanilla ID,
если они есть, вместо создания второго экземпляра того же человека.

ВПО требуют отдельной проверки производственных возможностей:

- Ford в Cork — кандидат моторизации, а не готовой танковой промышленности.
- Местные ремонтные/сборочные и судоремонтные мощности — кандидаты после проверки
  предприятия и дат, не повод выдать линкоры и авианосцы.
- Импортная лицензия/иностранный контракт — возможная ветка техники с политическими
  условиями; не открывать все британские ВПО простым снятием ограничений.
- ESB относится к энергетической/экономической механике, не автоматически к ВПО.
  Irish Steel относится к развитию конца десятилетия, не безусловному старту 1936.
- Harland & Wolff в Belfast не принадлежит IRE на старте. Любая его доступность
  требует отдельного соглашения/контроля и проверки прав на контент/графику.

Сначала реализовать одну обоснованную ВПО на существующем generic include,
затем проверить исследования, выпуск, traits и рост. Для отсутствующего требуемого
DLC определить fallback на обычные фирмы/идеи либо явно заявить зависимость;
не обещать одинаковую функциональность без проверки.

## 9. Последовательный план разработки и критерии готовности

1. **Базовая воспроизводимость.** Получить установленную HOI4 1.19.4.1 и список DLC;
   сохранить baseline-логи новой партии Kachanlot без изменений. Выписать фактические
   IRE history, персонажей, OOB, дерево, регионы и внешние события из игры.
   Готово: известны все базовые зависимости, стартовые значения и исходные ошибки.
2. **Исторический и технический контракт.** Создать реестр источников, временную
   шкалу, DLC-политику и ID/flags/variables registry. Согласовать исторический путь,
   границы альтернатив и поддержку старых save/старта 1939. Начальный приоритет —
   новая партия 1936; поддержку 1939 нельзя подразумевать без отдельной реализации.
   Готово: нет неразрешённых допущений о владельцах регионов и ролях лидеров.
3. **Минимальный старт IRE.** Реализовать сохранённый vanilla history + init,
   четыре духа, начальных персонажей, временные стандартные иконки, локализацию и
   небольшое дерево без сложных циклов. Готово: новый старт, корректные духи и их
   численные эффекты, правильное правительство, отсутствие новых ошибок загрузки.
4. **Вертикальный исторический фрагмент.** Фокусы → переговоры → событие IRE/ENG →
   ответ/отказ → замена экономического духа. Реализовать 1937 и 1938 отдельно,
   учесть британские передачи и `wtt_britain.24`. Готово: полный цикл с отказом,
   отсутствующим ENG и уже переданными территориями, без повторных наград.
5. **Общая экономика и оборона.** Добавить промышленную специализацию, импорт,
   резерв/подготовку, береговую оборону, одну ВПО; измерить силу вместе с законами
   Kachanlot. Готово: работающее производство и исследования, контролируемые
   расходы/бонусы, отсутствие бесконечных фабрик и людского резерва.
6. **Внутренние механики и Emergency.** Реализовать давление IRA/легитимность,
   нейтралитет и военные дефициты, решения, события, восстановление после кризисов.
   Готово: все диапазоны/пороги доступны игроку в UI, нет глобального частого опроса,
   сохранение/загрузка не сбрасывает прогресс.
7. **Альтернативные политические пути.** По одному: парламентская смена власти,
   социалистическая развилка, радикальные республиканцы, авторитарная правая.
   Готово: каждая ветка завершима, имеет собственные события/советников и последствия;
   взаимоисключения не допускают одновременно несовместимые правительства.
8. **AI, дипломатия и интеграция.** Исторический план, альтернативные правила,
   поведение ENG/GER/NIR, фракции, война/капитуляция/освобождение, ВПО и DLC fallback.
   Готово: наблюдательские прогоны до 1945 и воспроизводимость критических сценариев.
9. **Контентная доводка.** Портреты и иконки с проверенными правами, RU/EN тексты,
   исторические справки, tooltips, баланс и регрессия остального мода.
   Готово: выполнена тестовая матрица, известные ограничения записаны, изменения
   разбиты на обозримые PR. Только после этого оценивать достижение DLC-качества.

Зависимости: этапы 1–3 обязательны до любого расширения; 4–6 образуют историческое
ядро; альтернативы строятся на нём; графическая доводка не заменяет интеграционные
проверки. Не внедрять всю переработку одним неразделимым PR.
