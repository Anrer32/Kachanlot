## Требования последнего запроса и необходимые уточнения дизайна

| Требование уже задано пользователем | Что должен определить поузловой дизайн |
| --- | --- |
| Политическое равновесие и парламентская поддержка | Одна шкала или поддержка партий/коалиций; исходные значения, единицы, диапазоны, пороги законов и источники изменения |
| Историческая Fianna Fáil / de Valera | Коды и граф исторического пути, условия, результаты законов, план AI |
| Законная смена на Fine Gael или Labour | Какие P-коды ведут к выборам/коалиции, лидеры, условия мандата, последствия и повторные переходы |
| Национальное единство | Состав/лидер, условия образования и роспуска, совместимость с партийными маршрутами |
| Конституционные реформы 1936–1937 | Конкретные законы, даты/порядок, P-коды и зависимости |
| Монархия и отречение Эдуарда VIII | Историческая дата против реакции на фактический британский исход; альтернативный ENG и отсутствующий ENG |
| Референдум может провалиться | Формула/пороги или вероятность, состояние провала и возможность новой попытки; успех нельзя выдавать в completion_reward заранее |
| Внутренние и дипломатические последствия законов | Конкретные эффекты и адресаты, срок, запреты и отношения с действующим контентом ENG |
| Реальные взаимоисключения и блокировка после смены режима | Коды входов, доступность потомков, правила для уже завершённых узлов, связь с A-веткой без изменения её содержания |
| Повторяемые парламентские переговоры без бесконечной награды | Цена, cooldown, ограничение поддержки, набор партнёров и допустимые исходы |

Числа шкал, пороги, вероятности, календарь выборов и конкретные награды здесь
не выбраны. Названия партий не равны идеологическим группам HoI4: смена между
демократическими партиями должна менять действительное правительство/персонажа,
а не только вызывать `set_politics` с той же группой. Точные vanilla ID нельзя
вывести из фамилий или заменить вторыми версиями тех же персонажей вслепую.

## План проверок после получения дизайна

| Сценарий | Проверяемый результат |
| --- | --- |
| Исторический AI | Предпочитает маршрут de Valera, законопроекты доступны в ожидаемом порядке; явные веса и запись фактических выборов |
| Fianna Fáil → Fine Gael | Законное выполнение условий, смена правильного лидера/партии, доступность нового маршрута и блокировка несовместимого |
| Fianna Fáil → Labour | Аналогично, без фиктивной коммунистической революции вместо демократического перехода |
| Национальное единство → роспуск | Согласованный состав, поддержка и доступность узлов соответствуют новой коалиции |
| Внешняя смена режима | Несовместимый активный фокус отменяется/останавливается согласно дизайну; новый маршрут не застревает из-за вечных mutually_exclusive |
| Референдум: слабая/сильная поддержка | Реальны успех и отказ; флаги и последствия применяются по исходу один раз |
| Повторное событие/референдум | Нет повторной награды, противоречивых исходов и обхода условий через повторный вызов |
| Переговоры: повтор/максимум/cooldown | Цена и лимиты соблюдаются, повторный клик не создаёт PP или неограниченную поддержку |
| Отречение: исторический/альтернативный ENG | Нет двойного события, неверного адресата или выдуманной даты; обрабатываются отсутствие и война с ENG |
| Save/load и ежемесячный pulse | Правительство/поддержка/исходы не сбрасываются и не дублируются |
| Дерево и остальные направления | P01–P28 определены ровно по одному разу; ссылки разрешены, нет циклов; условия выполнимы в допустимых сценариях; E/M/D/A не изменены |
| Локализация/события | Полные RU/EN ключи, BOM, корректные namespaces/ID, event calls и scopes; отсутствуют сырые ключи и ссылки на несуществующие объекты |

Топологическая сортировка сама по себе не проверяет законную смену правительства:
необходим анализ состояния и взаимоисключений, затем реальные сценарии в HoI4.
Статические и игровые результаты записывать отдельно с commit/DLC/версией игры.
